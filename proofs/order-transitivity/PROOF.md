# 删除见证顺序的传递性与坏 star 判据

以下论证只使用 `K5` 的两个已认证类型；其完备性由
`../k5-completeness/PROOF.md` 的全枚举平面化证明给出。

写 `ab|cd` 表示边 `ab` 与 `cd` 交叉。两个无标号 `K5` 类型可取为

```text
A = {02|13, 02|14, 03|14, 03|24, 13|24}
B = {02|13, 02|14, 03|14, 04|23, 14|23}
```

设 `uv` 在一个这样的 `K5` 中未交叉。对其余三点定义
`i<j` 当且仅当 `ui|vj`。每个 `K4` 恰有一对独立边交叉，且
`uv|ij` 为假，所以 `i<j` 与 `j<i` 恰有一个成立。两个类型中的全部
未交叉边和所得顺序如下；反转 `(u,v)` 只会反转顺序。

| 类型 | 定向边 `(u,v)` | 三点顺序 |
|---|---|---|
| A | `(0,1)` | `2<3<4` |
| A | `(0,4)` | `3<2<1` |
| A | `(1,2)` | `3<4<0` |
| A | `(2,3)` | `4<0<1` |
| A | `(3,4)` | `0<1<2` |
| B | `(0,1)` | `2<3<4` |
| B | `(1,2)` | `4<3<0` |
| B | `(2,4)` | `3<0<1` |
| B | `(3,4)` | `2<0<1` |

表中没有有向三角。现在令 `(d,uv)` 是任意阶数图形中的删除见证。
其余点中的任意三点与 `u,v` 组成一个上述 `K5`，所以整个竞赛关系没有
有向三角。若 `i<j`、`j<k` 而 `i<k` 不成立，则 `k<i`，形成有向三角，
矛盾。因此这个关系是唯一全序。

对已经具有唯一顺序的非空见证，把 star 写成布尔字串 `b1...bm`。下列
条件等价：

1. 正项集合既不是前缀也不是后缀；
2. 字串至少改变两次取值；
3. 存在递增位置 `i<j<k`，使 `(bi,bj,bk)` 为 `010` 或 `101`。

至多一次变化恰好给出 `1*0*` 或 `0*1*`；至少两次变化时，从前三个常值
段各取一点就得到 `010` 或 `101`。这里是子序列，不要求三个位置相邻；
例如 `001100` 是坏字。

限制到 `{d,u,v,i,j,k}` 后，删除见证和两点比较保持，所以任意坏见证都有
一个六点坏见证限制。但该限制中出现的另一个好见证不一定能提升回全图，
因为外部顶点可能为它的边引入新的交叉。这正是局部替换路线的量词缺口。

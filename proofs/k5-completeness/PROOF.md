# K5 目录完备性及传递竞赛图的独立有限证明

日期：2026-09-26。程序只用标准库，不读任何封存目录、不调用 SAT。

## 本次补上的环节

此前的有限审计明确把“两张 K5 表的重标记闭包包含全部真实
交叉极大 K5 图形”记为前提 P5。本次给出一个直接穷举所有可能平面图形
组合数据的有限证明，因此对于实际简单图形，P5 不再需要依赖封存目录的
完备性声明。对于基础 SAT 对象，P5 本来就是显式约束。

这只闭合 K5 层及由它推出的顺序传递性；它不证明原 K17 存在性引理，
也不为历史 K17 UNSAT 提供证明证书。

## 1. 为什么旋转枚举完整

给一个真实交叉极大简单 K5 图形固定平面方向。在顶点0处，重标记其余
四个顶点，使逆时针旋转为 `(1,2,3,4)`。对其余四个顶点，邻居四元素
的循环排列恰有 `(4−1)!=6` 个；把最小邻居放在首位消除循环移位。
所以全部可能的规范化旋转系统恰好属于 `6^4=1296` 个枚举对象。
这个规范化只用顶点重标记，不假设凸性、直线性或独立重排任何见证顺序。

## 2. K4 层也直接以平面化检查

对每个四元组，不调用历史“旋转到交叉”的公式。直接尝试三种交叉匹配
以及每种匹配的两种交叉处循环旋转。把交叉替换为一个四价顶点，得到
5顶点8边的连通细分图；原四顶点的旋转由输入限制给定。

跟踪有向半边的面边界。恰有5个面当且仅当该旋转图的
`V−E+F=5−8+5=2`。交叉处两原边交替，所以这是一个合法的正常交叉。
三种匹配、两种方向穷尽了单交叉 K4 的可能性。对枚举得到的每个旋转，
检查通过的匹配及交叉方向至多一个，这一点由程序断言。

1296个候选中，恰好36个使每个 K4 都通过此检查。此时每个 K4 的交叉
对及交叉处循环次序已唯一确定。其余候选不可能是本任务中的真实图形。

## 3. 不遗漏任何沿边交叉次序

每个剩余 K5 有5个交叉点。对于每条原边 e，交叉伙伴集合 P(e) 已确定。
简单图形中，沿 e 遇到这些点的次序必是 P(e) 的一个排列，反过来没有
其他沿边次序需要考虑。因此直接枚举

    乘积（遍历全部10条边 e） |P(e)|!

种组合。36个候选总共只有650种沿边次序组合；程序全部检查，没有提前
把“不像可实现”的组合剪去，也没有时间上限或 UNKNOWN 分支。

对每种组合，将原边按其顺序细分，交叉点按照第2节已确定的四价旋转
连接。细分图必连通：每条 K5 原边仍是一条路径，所有新点都在某条路径上。
它有 `V=5+5=10`、`E=10+2·5=20`。

面跟踪得到 F；存在简单球面/平面图形当且仅当 F=12。充分性来自给
旋转图粘合定向顶点圆盘、边带及面圆盘，欧拉示性数2得到球面，然后
将交替的四价节点恢复为正常交叉。必要性来自任意实际图形的交叉顺序
必在上述排列枚举中，其平面化必满足欧拉公式。

每条原边的节点序列无重复；每个交叉节点只对应一对独立原边；不同
原边最多共享一次交叉。因此平面化恢复不会产生自交、邻边交叉、
重复交叉或三边同点，所得正是简单图形。

## 4. 完整计算结果与目录的精确对应

| 检查 | 精确数量 |
|---|---:|
| 规范化旋转系统 | 1296 |
| 全部 K4 均合法单交叉的候选 | 36 |
| 穷尽检查的沿边次序组合 | 650 |
| 至少有一个平面化的旋转系统 | 24 |
| 没有任何平面化的剩余候选 | 12 |
| 24个可实现表的全部重标记闭包 | 72 |

在字典序四元组 `0123,0124,0134,0234,1234` 上，以
`ab|cd=0, ac|bd=1, ad|bc=2` 编码，最终72表集合精确等于以下两种子的
重标记闭包：

    A=(1,1,1,1,1)，B=(1,1,1,2,2)。

这既不是只比较数量，也不是只验证目录内的表合法：程序先独立枚举完整
的平面化可能性，再验证两个集合逐项相等。`classification.json` 对每个
36候选保存完整旋转、交叉表、检查组合数、平面化数、最大面数，并为
每个正例保存一份显式平面化。

## 5. 传递竞赛图现在如何成立

给实际图形中的删除见证 `(d,uv)`，任取其余三点 i,j,k。五点
`{u,v,i,j,k}` 的交叉表必属于 A 或 B 的重标记闭包，且 uv 在其中未交叉。
`../order-transitivity/PROOF.md` 的九行表列出了 A、B 中全部未交叉边对应的三点全序，
没有一种产生有向三角。故整个竞赛图无有向三角，因而传递。

这一证明链使用了本次完全穷举的650种平面化和九行直接核查表；它不再
以 K5 目录完备性为未证前提。剩余的全局存在性问题仍是另一个命题。

```
python -B proofs/k5-completeness/enumerate_embeddings.py
```

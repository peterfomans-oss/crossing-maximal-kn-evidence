# License selection required

No public license has been selected for this release candidate. No license text is added automatically, and this directory does not grant permission to reuse the repository contents.

Before publishing:

1. choose a license appropriate for the code, documentation, data, and intended reuse;
2. add its complete text as a root `LICENSE` file;
3. replace `CHOOSE-A-LICENSE-SPDX-ID` in `CITATION.cff.template`;
4. resolve the third-party catalogue-data issue described in `THIRD_PARTY_NOTICES.md`;
5. add any required third-party license texts to this directory; and
6. run `python scripts/release_preflight.py --strict-release`.

Selecting a license is a decision for the repository owner. This release preparation intentionally does not make that choice.

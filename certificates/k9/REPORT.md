# K9：未交叉边不覆盖全部顶点的实际图形证书

日期：2026-09-26。

## 结论

**已取得实际简单图形层级的反例，而不再只是交叉表或一致旋转系统。**

存在一个 crossing-maximal 的简单 K9 图形，同时满足：

- 对每个删除顶点 d，都有非空删除见证，且恰好一个；
- 所有非空删除见证都不是 good（其 0/1 star 序列既非前缀也非后缀）；
- 未交叉边恰为 `01, 34, 56, 78`；
- 顶点 `2` 不 incident 于任何未交叉边。

因此，哪怕加上“每个 d 有非空见证且无 good”的背景，
“未交叉边的端点覆盖全部顶点”的加强也为假。

这仍然**不是**每条边都被交叉的例子，不是 K17 反例，也不否定原始
“all-edges-crossed K17 候选存在某个 good 见证”的特定命题。
这里并未获得“四条未交叉边是任意规模下界”的一般定理。

## 实际可实现性的独立证书

`planar/certificate.json` 给出：每条原边上所有交叉点的顺序、每个原顶点和交叉点
的端口循环顺序、每条平面化小边的端口配对，以及全部面边界。

`planar/check_certificate.py` 只使用 Python 标准库；不调用 SAT、图论包、恢复程序，
不导入封存编码器，也不诉诸 K5/K6 目录完备性。它独立检查：

1. crossing pairs 与原始模型完全一致，均为独立边，且每个 K4 恰一个交叉；
2. 每条原边经过且仅经过其声称的交叉点，构成无重复顶点的简单路径；
3. 每个交叉点四条分支按两种原边颜色交替；
4. 端口配对是无不动点对合，且与原边路径逐段吻合；
5. 平面化连通，统一循环方向导出的面置换恰好分割全部端口；
6. `V=135, E=288, F=155`，所以 `V-E+F=2`。

数学上的证书含义是：这些循环顺序及配对定义一个连通、可定向的组合映射；
沿面边界补圆盘得到 Euler 示性数为 2 的闭曲面，因此是球面。把每个四价
交叉顶点的交替分支看作一次横截交叉，就恢复了指定的简单 K9 图形。
每对原边至多相交一次、相邻原边不交叉，且有 `C(9,4)=126` 次交叉。
选择不在图上的一点作为无穷远点，得到平面图形。

这条证明无需用有限禁子图定理把“局部旋转检查通过”提升到全局可实现。

证书 SHA-256：

`0e4e3689c4088d890a600a7ea4832ac0496e83885e88132a5ff56c77bedca2b0`

## 见证和原模型审计

`check_counterexample.py` 独立重算完整交叉表、未交叉边，以及全部
`9*C(8,2)=252` 个候选 `(d,uv)`。其中 28 个是空见证，9 个非空。
对每个非空见证，还逐对检查竞赛关系确实与所列线性顺序一致。

| d | uv | 其余六点的顺序 | star | transitions |
|---|---|---|---|---:|
| 0 | 12 | 3,4,5,6,7,8 | 001100 | 2 |
| 1 | 02 | 3,4,5,6,7,8 | 110011 | 2 |
| 2 | 46 | 5,8,7,1,0,3 | 011000 | 2 |
| 3 | 24 | 8,7,6,5,0,1 | 001011 | 3 |
| 4 | 23 | 8,7,6,5,0,1 | 110100 | 3 |
| 5 | 68 | 7,0,1,3,4,2 | 011110 | 2 |
| 6 | 58 | 7,0,1,4,3,2 | 100001 | 2 |
| 7 | 08 | 5,6,3,4,2,1 | 110001 | 2 |
| 8 | 07 | 5,6,3,4,2,1 | 001110 | 2 |

非空二进制序列是前缀或后缀，当且仅当相邻位置至多一次变化；故表中均非 good。
反转顺序不改变变化次数。空见证不属于待反驳性质的非空 good 定义。

附加有限审计也全部通过：126 个 K5 属于明确两种 seed 的 72 项带标号闭包，
840 个不交三角形对的交叉数为偶数。公开检查器刻意不依赖旧 K6 目录；
实际图形的证明来自上面的显式球面证书。

K10 的 `result.json`、`independent-check.json` 和 `rotation.json` 也已阅读：
其旧记录报告 210 个 K6 正向归属、10 个非空坏见证、未交叉边仍为
`01,34,56,78`，未覆盖顶点为 `2,9`。本次没有为 K10 生成平面化，
所以本报告不提升其原有的 local/rotation 层级。

## 可复现检查

在仓库根目录执行（标准 Python 即可，不需要安装求解器）：

```powershell
python -B certificates/k9/check_counterexample.py
python -B certificates/k9/planar/check_certificate.py
python -B certificates/k9/check_embedding_independent.py
```

这些程序会在其目录写入新的检查结果；统一入口
`python -B audits/run_math_checks.py` 会改在临时副本运行，从而保持发布输入不变。
检查既有证书无需重新随机搜索。任何新候选都必须重新通过全部三个 checker。
